Notificaciones automáticas por WhatsApp

Cuando una orden pasa a LISTO PARA ENTREGAR, el sistema puede avisarle solo al cliente por WhatsApp (sin que nadie tenga que darle clic a nada). Para activarlo necesitas una cuenta de Twilio (es el servicio externo que realmente manda el mensaje).

¿Cómo saco las credenciales de Twilio?
  1. Crea una cuenta gratis en twilio.com/try-twilio (te pedirá tu correo y un número de teléfono para verificarte).
  2. En el Console de Twilio (la pantalla principal al entrar), copia el Account SID y el Auth Token — están arriba, en la sección "Account Info".
  3. Activa el WhatsApp Sandbox de prueba: en el menú, busca Messaging → Try it out → Send a WhatsApp message. Ahí te dan un número remitente (algo como whatsapp:+14155238886) y un código que cada cliente debe mandar una vez por WhatsApp para poder recibir tus mensajes de prueba.
  4. Para no depender del código de prueba y poder escribirle a cualquier cliente sin que te escriba primero, más adelante puedes pedir un número de WhatsApp Business propio dentro de Twilio (ya tiene costo mensual). Mientras tanto, el sandbox ya sirve para probar que todo funciona.
  5. Pega esos tres datos abajo y guarda. Cada mensaje enviado tiene un costo pequeño (unos centavos de dólar) que Twilio cobra a la tarjeta que registres en tu cuenta de Twilio — el sistema no maneja ningún pago, eso es directamente con ellos.
Si no llenas el Account SID, el Auth Token y el número remitente, esta casilla no tiene efecto: el sistema sigue usando el botón manual de "Avisar por WhatsApp" como hasta ahora.
